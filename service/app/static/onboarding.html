How to set this up (guide)
  1. Go to ngrok.com and sign up (free).
  2. Dashboard → "Your Authtoken" → copy it → paste it above.
  3. Dashboard → Domains → "+ New Domain" → claim your free static domain → paste the bare domain (no https://) above.
  4. Save this page, then re-run the launcher once so the tunnel comes up. After that, open @BotFather → /newapp → pick your bot → title "Live Chart" → /empty for the photo and GIF prompts → Web App URL = https://<your ngrok domain> → short name chart → paste the resulting t.me/<bot>/<name> link above.

The free ngrok tier shows a one-time "Visit site" page to browser visitors; a paid ngrok domain removes it. None of this is required to trade — the strategy, risk rules, and alerts all work without it.
