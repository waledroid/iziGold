# UI Plan A (Phases 1–2): Heartbeat, Dashboard, Trades, Screenshots

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** EA heartbeat + local web dashboard (live state, equity curve, strategy comparison, signal log), then trade events + chart screenshots + history view. Spec: `docs/superpowers/specs/2026-07-31-ui-design.md` (§2–§7). Telegram two-way and service-rendered charts are Plan B.

**Architecture:** New service endpoints on the existing FastAPI app (`/heartbeat`, `/trade-event`, `/screenshot`, `/ui` + `/ui/*` JSON). New SQLite tables `heartbeats` (60 s downsampled) and `trades`. One static HTML dashboard, plain JS polling. EA side: a new `CUiApi` include (timer-driven heartbeat + trade-event/screenshot upload) and a small trade-event sink interface on `CTradeManager`. Remote switch rides the heartbeat response (at-least-once until the EA reports the new id active).

**Tech Stack:** Python 3.11+/FastAPI/pydantic v2/sqlite3/pytest; MQL5 (compile deferred to user's Windows checklist); vanilla HTML/JS.

## Global Constraints

- Python tests: run from `service/` with `.venv/bin/python -m pytest`; fast suite must stay green after every task.
- MQL5 cannot compile here — MQL5 tasks end with recorded self-checks; MetaEditor compile is in the final manual checklist.
- Fail-open is absolute: heartbeat/trade-event/screenshot failures never block or delay trading; UI is read-only toward trading except the switch command (bar-boundary apply, compiled-in ids only). No UI path touches the kill switch.
- Service port default is 9000. New EA input `UiBaseUrl` default `"http://127.0.0.1:9000"`.
- Heartbeat cadence 5 s (`EventSetTimer(5)`); db persistence downsampled to ≥ 60 s apart; `/ui/state` staleness threshold 30 s.
- Screenshot retention: keep the newest 500 PNGs in `service/screenshots/`.
- Commits: repo style + trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

```python
    def insert_heartbeat(self, hb: dict) -> bool:
        now = int(time.time())
        last = self.conn.execute("SELECT MAX(ts) FROM heartbeats").fetchone()[0]
        if last is not None and now - last < 60:
            return False
        self.conn.execute(
            "INSERT INTO heartbeats (ts, equity, balance, floating_pl, open_count,"
            " kill_switch, exposure_min, active_strategy) VALUES (?,?,?,?,?,?,?,?)",
            (now, hb["equity"], hb["balance"], hb["floating_pl"], hb["open_count"],
             int(hb["kill_switch"]), hb["exposure_min"], hb["active_strategy"]))
        self.conn.commit()
        return True

    def equity_series(self, limit: int = 1440) -> list:
        rows = self.conn.execute(
            "SELECT ts, equity, balance, floating_pl FROM heartbeats"
            " ORDER BY ts DESC LIMIT ?", (limit,)).fetchall()
        return [{"ts": t, "equity": e, "balance": b, "floating_pl": f}
                for t, e, b, f in reversed(rows)]
```

```python
@app.post("/heartbeat", response_model=HeartbeatResponse)
def heartbeat(hb: HeartbeatRequest):
    app.state.latest_heartbeat = (time.time(), hb)
    app.state.db.insert_heartbeat({**hb.model_dump(exclude={"positions"}),
                                   "open_count": len(hb.positions)})
    if app.state.pending_switch and hb.active_strategy == app.state.pending_switch:
        app.state.pending_switch = None
    return HeartbeatResponse(switch_to=app.state.pending_switch)


@app.post("/ui/switch")
def ui_switch(body: dict):
    sid = str(body.get("strategy_id", "")).strip()
    if not sid:
        return {"pending": None}
    app.state.pending_switch = sid
    return {"pending": sid}
```
